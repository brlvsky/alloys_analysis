# PSD-Lab 1.1 — анализ гранулометрии порошков

Программа для учебного научного проекта «Новые материалы для аддитивного производства аэрокосмической техники».
Она открывает файлы лазерного анализатора Fritsch ANALYSETTE 22 и обычные таблицы Excel/CSV и строит:

- графики распределения частиц по размерам;
- сводную таблицу d10, d50, d90, D[4,3], долей по фракциям;
- отчёт для руководителя — один HTML-файл и документ Word, — и таблицу Excel;
- популяции частиц, окна для СЛС/СЭЛС, выход годного, удельную поверхность, упаковку слоя, кинетику помола;
- базу данных «структура — свойства» и график связи любых двух величин;
- калькулятор плотности состава и методику измерения с чек-листом качества;
- **расчёт шихты** (новое в 1.1): пересчёт ат.% → мас.%, добавки, навески на каждую загрузку мельницы,
  лигатура и бланк навесок для печати.

---

## 1. Как получить и запустить программу

**Если есть архив `PSD-Lab-1.1-win64.zip`:** распакуйте его в любую папку (лучше не в «Program Files») и запустите
`PSD-Lab\PSD-Lab.exe`. Устанавливать ничего не нужно, Python не нужен.

**Если архива нет — собрать самому (один раз):**

1. Скачайте проект: на странице репозитория на GitHub выберите ветку `claude/new-session-1tz13i`,
   нажмите **Code → Download ZIP**, распакуйте, например, в `C:\psd-lab`.
2. Дважды щёлкните **`build_exe.bat`**. Если Python не установлен, он поставит его сам
   (или откройте PowerShell и выполните `py install 3.12`).
3. Через 5–15 минут откроется папка `dist`: там `PSD-Lab\PSD-Lab.exe` и архив `PSD-Lab-1.1-win64.zip`.

**Если Windows Defender или SmartScreen ругается** — это частая ложная тревога на самодельные программы без
цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

**Перенос на другой компьютер:** скопируйте архив zip и распакуйте. Чтобы перенести и свои данные (базу,
настройки), скопируйте ещё папку `PSD-Lab-data` и положите её рядом с `PSD-Lab.exe`.

## 2. Первый запуск

На стартовой странице три кнопки: **«Открыть файлы…»**, **«Открыть папку…»** и **«Открыть примеры»**
(примеры — ваши файлы 2020 года, лежат в папке `examples` рядом с программой). Ниже — список последних файлов.

**Файлы и целые папки можно просто перетащить мышью из Проводника на окно программы.**

Программа запоминает размер окна и открытые файлы и в следующий раз откроет их сама.

Если всё мелкое или крупное: **Вид → Масштаб интерфейса** (Авто, 100, 110, 125, 150, 175, 200 %).
Программа предложит перезапуститься.

## 3. Окно программы

- **Панель кнопок** сверху: Открыть, Папка, Примеры, PNG (сохранить текущий график), Отчёт (HTML),
  Word (отчёт в Word), Excel, Обновить (перечитать файлы), Настройки, Справка.
- **F1** — это руководство прямо в программе (Справка → Руководство пользователя).
- **Подержите мышь** над вкладкой, заголовком панели, полем результата (d10, span…) или заголовком столбца
  сводки — всплывёт короткое пояснение, что это такое.
- **Слева — «Файлы и образцы».** Флажок у образца — включить или выключить его в сравнении, сводке и отчёте.
  Значок рядом — флаг качества (см. раздел 5). **F2** — переименовать образец.
- **Ниже — «Свойства»** выбранного образца (прибор, дата, обскурация, результат) и
  **«Замечания по качеству»** простыми словами.
- **Внизу — «Журнал»** (что загружено, что пропущено и почему) и строка состояния (сколько образцов,
  сколько с замечаниями, где база).

**Наведите мышь на любой график** — появится подсказка со значениями в этой точке (размер, ΣQ, Q в столбике,
значения всех кривых и т. п.).

Повторные измерения с одинаковым названием (например, два N/C) автоматически усредняются.
Отключить: **Вид → Усреднять повторы**.

## 4. Вкладки

| Вкладка | Что показывает |
|---|---|
| **Распределение** | Столбики Q, % (доля в интервале) и кривая ΣQ, % (накопленная доля) для выбранного образца. Под графиком — поля с d10, d50, d90, span, D[4,3], D[3,2], долями фракций и обскурацией. Флажок **«Логарифмическая ось X»** (или Вид → Логарифмическая ось X распределения): удобно, когда в порошке есть и мелочь в единицы микрон, и крупные частицы в сотни. Тогда столбики — доли в логарифмических интервалах (1/10 декады); где у прибора нет точек (сетка 0,1 → 2 мкм), интервалы объединены, а то, что левее оси, подписано на графике. Настройка действует и на PNG, и на отчёты. |
| **Сравнение** | Накопленные кривые всех отмеченных образцов на одном графике (ось X логарифмическая или линейная). Цвет — образец, тип линии — файл. Режим **«два образца „до и после“»**: выберите A (например, порошок без добавки) и B (с добавкой) — сверху распределения обоих, снизу разность накопленных кривых (синее — B мельче, оранжевое — B крупнее), таблица «B − A» для d10, d50, d90, D[4,3], долей и итог одной строкой. Разница меньше 2 п.п. — в пределах разброса повторов. |
| **Сводка** | Таблица всех показателей. Щелчок по заголовку — сортировка. Выделите строки и нажмите **Ctrl+C** — вставятся в Excel. Колонка **QC** — сколько пунктов чек-листа качества выполнено. |
| **Популяции** | Разложение распределения на группы частиц (логнормальные компоненты): доля, мода, медиана, σg каждой; R². Например, у П/С мелкая популяция — 30–80 % объёма. |
| **Технология** | «Окна СЛС / СЭЛС»: какая доля порошка попадает в окно каждой технологии (только факты, без вердикта). «Выход годного»: сколько граммов из 1 кг останется после рассева на заданное окно и выполняются ли требования к порошку. |
| **Поверхность** | Удельная поверхность (м²/г) и главный вывод: «фракция < 15 мкм — X % объёма, но Y % поверхности» — это риск набора кислорода. |
| **Упаковка** | Оценка пористости слоя для двухмодальных порошков и оптимальная доля мелкой фракции. Это верхняя оценка (сухие сферы без слипания). |
| **Кинетика** | d10/d50/d90 и доли от времени обработки (время берётся из названия «6ч» или задаётся вручную). |
| **Шихта** | Расчёт шихты: состав сплава → массовые доли → навески на каждую загрузку барабана, варианты с добавками, лигатура, бланк навесок. Подробно — ниже, «Расчёт шихты». |
| **База данных** | Партии, их измерения, СЭМ (с превью снимка), РФА, химанализ, режимы печати, механические испытания, сохранённые рецепты шихты — с кнопками «Добавить / Изменить / Удалить». |
| **Методика** | Методика измерения на лазерном анализаторе и чек-лист качества для выбранного измерения. |

**Анализ → Структура — свойства** — график любых двух числовых величин из базы (например, d50 и прочность)
с подписями партий и линией тренда. R² показывается только когда точек 3 и больше.

**Сервис → Плотность состава** — плотность сплава по составу (ат.% или мас.%), добавки Si, C, Y₂O₃,
сравнение с Ti6Al4V (4,43 г/см³) и целью ТЗ (легче на 10–15 %). **Точный состав TANMB неизвестен —
его нужно взять у руководителя.** Простая оценка (правило смесей) для γ-TiAl ошибается на несколько процентов —
вывод о цели ТЗ делайте по измеренной плотности.

У каждой оценки в программе есть строка **«Допущения:»** — что упрощено и где проверять.

### Расчёт шихты (вкладка «Шихта»)

Открыть: вкладка **«Шихта»** или **Сервис → Расчёт шихты**. Программа сама пересчитывает состав из атомных
процентов в массовые, учитывает добавки и раскладывает партию на загрузки мельницы. Всё пересчитывается
сразу, как только вы меняете любое поле.

**Что вводить (слева):**

1. **Состав сплава** — строкой «число + элемент» через дефис, например `50Ti-44Al-4,9Nb-1Mo-0,1B`, и
   выбрать, в чём он: ат.% или мас.%. Элемент без числа — основа (остаток до 100 %). Точка и запятая — одинаково.
2. **Добавки** — кнопка «Добавить…»: компонент (элемент или соединение, например `CeO2`), количество,
   единицы (ат.%, мол.% или мас.%) и как вводится:
   - **за счёт** элемента (например, за счёт Ti) — этого элемента становится меньше, сумма остаётся 100 %;
   - **сверх** — добавка добавляется к сплаву, остальное пропорционально уменьшается.

   «Считать»: каждая добавка отдельно, все вместе или и так, и так — для каждого варианта будет своя строка.
3. **Партия и загрузки** — сколько смеси нужно (г), ёмкость барабана (г), запас на потери (%), при желании
   соотношение шары : порошок. Режим «полные загрузки» — каждый барабан полный, в конце может остаться
   **избыток**; «равные загрузки» — партия делится поровну.
4. **Лигатура** (необязательно):
   - «рассчитать лигатуру» — впишите, какие порошки вводятся чистыми (например, `Al`), остальное программа
     соберёт в лигатуру и скажет её состав;
   - «лигатура задана» — впишите состав имеющейся лигатуры, программа подберёт, сколько её и каких чистых
     порошков взять, и покажет, насколько получившийся состав отличается от нужного.

**Что получается (справа):** таблица вариантов (мас.% каждого компонента, кислород из оксидов, плотность по
правилу смесей и разница с Ti6Al4V), навески на одну загрузку и на всю партию, лигатура. В поле
**«Навески:»** выберите, по какому варианту печатать навески.

**Кнопки:**

- **Бланк навесок…** — документ Word (или HTML) для печати: таблица «компонент | навеска | точность весов |
  фактически взвешено | подпись», отдельно на каждую загрузку (флажок «бланк по загрузкам»).
- **Excel…** — книга с листами «Состав», «Варианты», «Загрузки», «Закупка», «Лигатура», «Бланк навесок».
- **Сохранить рецепт… / Открыть рецепт…** — весь ввод в файл `.json` (то же в меню Файл), чтобы вернуться к
  расчёту потом или отправить коллеге.
- **В карточку партии…** — сохранить рецепт в базу данных к партии (видно на вкладке «База данных» →
  «Шихта»).

**Пример коллеги** (кнопка «Загрузить пример»): сплав 50Ti-44Al-4,9Nb-1Mo-0,1B (ат.%), добавки 0,5 ат.% C,
0,5 ат.% Si и 1,2 мол.% CeO₂ — все за счёт Ti; нужно 1500 г, барабан на 200 г; алюминий вводится чистым,
остальное — лигатурой. Программа даёт:

- базовый состав в мас.%: Ti 57,91; Al 28,73; Nb 11,02; Mo 2,32; B 0,026;
- 8 полных загрузок по 200 г = 1600 г (избыток 100 г);
- на одну загрузку со всеми добавками: Ti 107,57 г; Al 55,81 г; Nb 21,40 г; Mo 4,51 г; B 0,051 г;
  C 0,282 г; Si 0,660 г; CeO₂ 9,71 г;
- лигатура — 72,09 % шихты, чистый Al — 27,91 %;
- предупреждение: кислород из CeO₂ ≈ 0,9 мас.% — больше ориентира 0,2 %; это не норма, а повод уточнить
  требования к кислороду.

**Допущения:** порошки смешиваются идеально; потерь сверх заданного запаса нет; порошки считаются
чистыми (чистоту можно задать в файле рецепта — тогда навеска пересчитывается на основной компонент);
атомные массы — стандартные IUPAC (чтобы сверить с ручным расчётом на округлённых массах, их можно
переопределить в `settings.json`, поле `atomic_mass_overrides`); плотность по правилу смесей — грубая оценка.

## 5. Флаги качества

| Значок | Уровень | Когда ставится | Что значит |
|---|---|---|---|
| красный круг | **ОШИБКА** | обскурация < 0 | фон записан неверно, результату доверять нельзя — перемерить |
| красный круг | **ОШИБКА** | кривая не монотонна | данные повреждены или сдвинуты |
| жёлтый треугольник | **ВНИМАНИЕ** | обскурация > 40 % | риск многократного рассеяния |
| жёлтый треугольник | **ВНИМАНИЕ** | кривая не доходит до 100 % (больше чем на 0,6) | часть порошка вне диапазона; кривая **не** растягивается до 100 % |
| жёлтый треугольник | **ВНИМАНИЕ** | повторы расходятся > 2 п.п. | повторы плохо сходятся |
| синий круг | **ИНФО** | TradeOff в файле различается > 5 раз | степень сглаживания разная, форму пиков сравнивать осторожно |

В данных 2020 года: все образцы с Si — ОШИБКА (отрицательная обскурация), П/С +1,5Y2O3 — ВНИМАНИЕ (обскурация 64 %),
все образцы N/C — ИНФО (разный TradeOff).

## 6. Свои таблицы: какие форматы понимаются

Кроме файлов прибора Fritsch, программа читает **.xlsx, .xls, .csv, .txt** — экспорты других анализаторов
(Malvern, Horiba, Microtrac, Sympatec, Beckman и т. п.) и таблицы, набранные руками. Она сама ищет на листе:

- **столбец размеров** — по возрастанию или по убыванию (как в ситовом анализе), в мкм, мм, нм или номерах
  сит (меш, по стандарту ASTM E11); единицы берутся из заголовка («Размер, мм») или из ячеек («45 мкм»);
- или **столбец фракций текстом**: «15–45», «−45+20», «<20», «>500», «+150», «поддон»;
- рядом — **проценты**, любые из этих видов:
  - накопленная «мельче размера» (проход, ΣQ, undersize);
  - накопленная «крупнее размера» (остаток, R, oversize) — пересчитывается в «мельче»;
  - доли по интервалам или по ситам (в сумме ~100);
  - плотность q3 (если столбец так и подписан — «q3lg», «density»);
- числа можно писать текстом и с «%», доли — в процентах или в долях единицы;
- таблица может быть **«боком»** (размеры в строке, каждый образец — строка), у каждого образца может быть
  **свой столбец размеров**, на листе может быть **несколько таблиц** одна под другой;
- название образца — из заголовка столбца (или ячейки «Sample Name», «Образец»), иначе из имени листа или файла.

**Как прочитан файл** — написано в журнале внизу и в «Свойствах» образца (например, «размеры в мм переведены
в мкм», «остаток на сите пересчитан»). Кривые никогда не обрезаются и не растягиваются до 100 %.

**Если программа не нашла данные или поняла их не так** — **Файл → Импорт таблицы вручную…** (или
«Настроить импорт выбранного файла…»). Откроется мастер: выберите лист, столбец размеров, строки, столбцы
с процентами, вид данных и единицы — внизу сразу видно, что получится. Настройка запоминается для этого
файла: в следующий раз он откроется так же. Если автомат ничего не нашёл, программа сама предложит мастер.

Пример `мой порошок.csv`:

```
Размер, мкм;Партия 12;Партия 13
1;0,5;0,3
5;8,2;4,1
10;31,0;18,5
20;68,4;55,0
45;95,1;90,2
63;99,6;98,8
100;100;100
```

Пример ситового анализа, набранного руками (тоже читается):

```
Сито, мкм;Остаток на сите, %
150;2,1
106;8,4
63;35,0
45;30,2
20;19,8
Поддон;4,5
```

## 7. Отчёт и Excel

- **Отчёт** (кнопка «Отчёт» или Файл → Экспорт) — один файл `report.html`, все картинки внутри.
  Его можно просто отправить руководителю. Внутри: сводная таблица, замечания по качеству, сравнение
  (и «до и после», если пара выбрана), графики по образцам, популяции, окна СЛС/СЭЛС, выход годного,
  поверхность, упаковка, кинетика, партии.
- **Word** (кнопка «Word») — тот же отчёт в виде документа `report.docx`: его можно поправить, дописать
  выводы и сохранить в PDF (в Word: Файл → Сохранить как → PDF). Заголовки разделов сделаны стилями Word,
  поэтому оглавление вставляется одной командой (Ссылки → Оглавление).
- **Excel** — `summary.xlsx`: листы «Сводка», «Кривые», «Флаги», «Популяции», «Окна печати», «Выход годного»,
  «Поверхность», «Упаковка», «Кинетика» (и «До и после», если пара выбрана).
- **PNG** — графики в «публикационном» стиле (10×6 дюймов, 200 dpi) для отчёта по проекту.
  Подписи осей — английские (как на образце) или русские: Сервис → Настройки.

## 8. Где хранятся данные и как сделать резервную копию

Все ваши данные — в папке **`PSD-Lab-data`** рядом с `PSD-Lab.exe`:

- `psd.sqlite` — база данных «структура — свойства»;
- `settings.json` — настройки.

Рецепты шихты, сохранённые «в карточку партии», тоже лежат в базе.

**Резервная копия — просто скопируйте папку `PSD-Lab-data`** (например, на флешку или в облако).
Если писать рядом с программой нельзя, данные лежат в `%APPDATA%\PSD-Lab`.

Программа и сама делает копии базы: раз в день при запуске — в папку `PSD-Lab-data\backups`
(хранятся последние 10), а также перед удалением партии. Вернуть базу: **База → Восстановить из резервной
копии…** (текущая база перед этим тоже сохраняется, так что ошибку можно отменить).

Каждый открытый файл автоматически попадает в базу. Один и тот же файл второй раз не добавляется,
даже из другой папки. Исходные файлы программа **никогда не изменяет**.

---

## 9. Без окна (пакетный режим)

```
PSD-Lab.exe --batch C:\папка\с\файлами --out C:\папка\для\результатов
```

Создаёт графики PNG, `summary.xlsx`, `report.html`, `report.docx` и `batch_log.txt`, измерения добавляются в базу
(`--no-db` — не добавлять).

## 10. Если что-то не так

- **«Не удалось записать summary.xlsx»** — файл открыт в Excel, закройте его.
- **Файл пропущен** — причина написана в журнале внизу окна.
- **Всё мелкое** — Вид → Масштаб интерфейса.
- **Случайно удалили данные в базе** — База → Восстановить из резервной копии… и выберите копию за нужный день.
- **Не открывается отчёт Word** — нужен Word или бесплатный LibreOffice; HTML-отчёт открывается любым браузером.
- **Программа не запускается** — запустите `PSD-Lab.exe --selftest`. Она сама проверит себя и сохранит
  скриншоты и `selftest.txt` в папку `out\screens`. Пришлите их разработчику.

## 11. Открытые вопросы к руководителю

- Что означают обозначения **N/C** и **П/С**, какой маршрут получения порошков.
- Точный состав **TANMB**.
- Происхождение данных **6 / 8 / 10 ч** (`Расчет.xlsx`): какой материал и какая обработка.
- Есть ли **СЭМ** и химанализ на **O / N** для этих партий.
- Исходный файл «Расчет грансостава.xlsx».
- На какой машине планируется печать — под неё уточнить окна СЛС/СЭЛС и требования к порошку.
- Шихта: добавки C, Si, CeO₂ вводятся **по отдельности** (разные партии) или **все вместе**?
- «1,2 CeO₂» — это **мол.%** или **мас.%**? (программа считает мол.%, можно переключить.)
- Откуда числа в Excel-таблице с лигатурой (71,38 / 28,62 и Ti 80,85; Nb 15,87; Mo 3,24; B 0,04)? По
  составу 50Ti-44Al-4,9Nb-1Mo-0,1B без добавок должно быть 71,27 / 28,73 и Ti 81,25; Nb 15,45; Mo 3,26;
  B 0,04 — вероятно, там другие атомные массы или состав.
- Какой допустимый уровень кислорода в сплаве (программа предупреждает выше 0,2 мас.% — это ориентир).

## Для разработчика

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m psd_lab                              окно программы
.venv\Scripts\python -m psd_lab --batch data\raw --out out   без окна
.venv\Scripts\python -m psd_lab --selftest                   самопроверка, скриншоты в out\screens
.venv\Scripts\python -m pytest                               тесты
build_exe.bat                                                сборка exe и zip
```

Ядро (`psd_lab/core`) не зависит от окна и покрыто тестами; окно — `psd_lab/gui` (Tkinter).
Решения, формулы и их источники — в `NOTES.md`. Исходные данные — `data/raw` (только чтение).
