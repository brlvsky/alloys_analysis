# Методика измерения гранулометрического состава порошков методом лазерной дифракции

Прибор: Fritsch ANALYSETTE 22 MicroTec plus (мокрый диспергатор). Проект «Новые материалы для аддитивного производства аэрокосмической техники».

Методика написана по проблемам, найденным в измерениях 2020 года (файлы N_C_.xls, TANMB_.xls). Конкретные числа из стандартов здесь не приводятся: где они нужны, стоит пометка «уточнить по тексту стандарта». Числа для настройки прибора берутся из его руководства.

## 1. Что было не так в данных 2020 года

- **Отрицательная обскурация** у всех образцов с кремнием (M4251 −53 %, M4253 −51 %, M4322 −37 %). Обскурация не может быть отрицательной: фон записан неправильно (например, при загрязнённой кювете или пузырьках), и распределение по таким измерениям ненадёжно.
- **Обскурация 64 %** у П/С +1,5Y2O3 (M4347): суспензия слишком концентрированная, возможно многократное рассеяние, и прибор «видит» частицы мельче, чем они есть.
- **TradeOff (сглаживание) подбирался автоматически** и у образцов одного файла различается в 41 раз. Форму пиков таких измерений сравнивать нельзя: одна кривая сглажена сильнее другой.
- **Повторы делались из одной и той же суспензии** (две записи подряд). Они показывают только сходимость прибора (у N/C расхождение ≤ 0,8 п.п.), но не разброс от отбора пробы.
- **Расчёт по Фраунгоферу**: для частиц меньше ~10 мкм он может давать ложный «горб» ниже 1 мкм и смещать мелкую фракцию. У П/С мелкая популяция — 30–80 % объёма, поэтому это важно.
- **Происхождение мелкой моды у П/С неизвестно**: агломераты или реальные мелкие частицы — по одной кривой не различить.

## 2. Отбор и подготовка пробы

- Перед отбором порошок перемешать. Пробу отбирать делителем проб (желобковым или вращающимся), а не «с верха банки».
- Для каждой партии готовить **не меньше трёх независимых подпроб**: каждая подпроба отбирается и диспергируется заново. Это и есть «повторы» для отчёта.
- Диспергирующую жидкость и при необходимости ПАВ выбрать так, чтобы порошок не растворялся и не окислялся. Записать выбор в журнал. Рекомендации — уточнить по тексту ISO 13320 и руководству прибора.

## 3. Контроль фона

- Фон (чистая жидкость) измерять **перед каждой пробой**, после промывки кюветы.
- Фон должен быть стабильным: два измерения фона подряд совпадают. Если нет — промыть систему ещё раз, удалить пузырьки.
- После добавления пробы обскурация **обязана быть положительной**. Отрицательная обскурация означает испорченный фон: измерение повторить с новым фоном. Программа PSD-Lab ставит на такие измерения флаг ОШИБКА.

## 4. Окно обскурации

- Добавлять пробу до попадания обскурации в рабочее окно прибора. Границы окна — по руководству прибора и ISO 13320 (уточнить по тексту стандарта).
- Слишком высокая обскурация — риск многократного рассеяния, слишком низкая — шум. Программа ставит флаг ВНИМАНИЕ при обскурации выше 40 %. Этот порог взят из ТЗ проекта, при необходимости поменять его по руководству прибора.
- Для серии сравниваемых образцов держать обскурацию примерно одинаковой.

## 5. Параметры расчёта

- **TradeOff (регуляризацию) зафиксировать** одним значением для всей серии. Автоподбор отключить: он делает степень сглаживания разной.
- **Модель расчёта.** Фраунгофер не требует оптических констант, но для частиц размером в несколько длин волн и меньше ошибается. Для мелкой фракции TiAl предпочтительнее теория Ми. Для неё нужны комплексный показатель преломления материала (n и k) и показатель преломления жидкости. Значения для TiAl взять из литературы или у производителя прибора (уточнить). Модель и константы указывать в отчёте.
- Записывать в журнал: дату, номер измерения, модель, константы, TradeOff, обскурацию, мощность ультразвука, скорость насоса.

## 6. Тест ультразвуком (агломераты или настоящие частицы)

- Одну и ту же подпробу измерять при нескольких мощностях (или длительностях) ультразвука: от выключенного до максимального, ступенями.
- Если с ростом мощности мелкая мода растёт, а крупная уменьшается, в порошке есть **агломераты**, и ультразвук их разбивает.
- Если распределение не меняется, частицы настоящие.
- Если растёт доля очень мелких осколков, ультразвук может **разрушать хрупкие частицы**. Это тоже важно для интерметаллидов TiAl.
- Результат теста сравнить со снимками СЭМ той же партии.

## 7. Как представлять результаты

- Кривые: накопленная доля ΣQ₃(x) и плотность q₃(x) или q₃*(ln x), подписи осей и обозначения — по ISO 9276-1 (уточнить по тексту стандарта).
- Средние размеры и моменты (D[4,3], D[3,2]) — по ISO 9276-2.
- Метод и условия измерения (модель, оптика, диспергирование, обскурация) — по ISO 13320.
- Характеризация порошка для аддитивного производства: гранулометрия, морфология, химия, текучесть, плотность — по ISO/ASTM 52907 и ASTM F3049. Перечень показателей и методы уточнить по тексту стандартов.
- Кривые **не обрезать и не перенормировать**. Если кривая не доходит до 100 %, так и показывать.
- Для каждой партии: среднее по независимым подпробам и разброс; флаги качества; заполненный чек-лист (ниже).

## 8. Чек-лист качества измерения

Отмечается в программе PSD-Lab на вкладке «Методика» для каждого измерения и хранится в базе. В сводке показывается как «QC: 3/5».

1. Фон проверен: стабилен, обскурация после добавления пробы положительная.
2. Обскурация в допустимом окне. Ставится автоматически по данным прибора: больше 0 и не больше 40 %.
3. Повторы сделаны из независимых подпроб, а не из одной суспензии.
4. Проведён тест ультразвуком (раздел 6).
5. Модель расчёта указана: Фраунгофер или Ми, для Ми — с оптическими константами.
