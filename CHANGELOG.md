# Список изменений PSD-Lab

## 1.1 — расчёт шихты

**Новое: вкладка «Шихта»** (Сервис → Расчёт шихты)

- Пересчёт состава из ат.% в мас.% и обратно; составы вида `50Ti-44Al-4,9Nb-1Mo-0,1B`, соединения (`CeO2`).
- Добавки в ат.%, мол.% или мас.%, «за счёт» элемента или «сверх»; варианты «каждая отдельно» и «все вместе».
- Кислород из оксидных добавок и предупреждение выше 0,2 мас.% (ориентир, настраивается).
- Раскладка партии на загрузки мельницы: полные или равные загрузки, запас на потери, избыток, масса шаров.
- Навески на загрузку и на всю партию, точность весов для каждой навески.
- Лигатура: рассчитать состав лигатуры или подобрать навески под имеющуюся лигатуру
  с показом отклонения от целевого состава.
- Плотность каждого варианта по правилу смесей и разница с Ti6Al4V.
- Бланк навесок для печати (Word / HTML), книга Excel (Состав, Варианты, Загрузки, Закупка, Лигатура,
  Бланк навесок).
- Рецепты: сохранить и открыть файл `.json` (Файл → Открыть / Сохранить рецепт шихты), сохранить в карточку
  партии (база данных, подвкладка «Шихта»). База обновляется сама, старые базы 1.0 открываются.
- Пример коллеги загружается кнопкой «Загрузить пример».
- Атомные массы — единая таблица для всей программы; калькулятор плотности (М7) теперь использует её же.

**Также после 1.0**

- Оформление ближе к Windows 95: без «LCD-окошек» и градиентов; сдвиг графика мышью в 7–8 раз быстрее.
- Новые иконки «Обновить» и «Настройки».
- Формулы сверены с источниками (модель упаковки, плотности элементов), ссылки в NOTES.md.
- Отчёт в Word (`report.docx`) в дополнение к HTML.
- Сравнение двух образцов «до и после»: разность кривых и таблица «B − A».
- Перетаскивание файлов на окно, автоматические резервные копии базы и восстановление из копии.
- Встроенное руководство (F1) и всплывающие подсказки при наведении на вкладки, панели и показатели.
- Логарифмическая ось X на графике распределения.
- Распознавание таблиц любой формы (разные приборы, ручные таблицы, ситовый анализ) и мастер ручного импорта,
  который запоминает настройку для файла.

## 1.0 — первая полная версия

- Чтение файлов Fritsch ANALYSETTE 22 и произвольных таблиц; d10/d50/d90, span, D[4,3], D[3,2], доли по окнам,
  флаги качества, усреднение повторов.
- Графики в публикационном стиле, сравнение, сводка, отчёт HTML и Excel, пакетный режим.
- Модули: популяции, окна СЛС/СЭЛС и выход годного, удельная поверхность, упаковка, плотность состава,
  кинетика помола, база «структура — свойства», методика и чек-лист качества.
- Окно в стиле Windows 95, сборка exe.
